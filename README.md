# Blank Component Studio Project

This is a minimal component studio project created with Component Studio.

## Project Structure

```
{your-project-name}/
  ├── src/
  │   └── {your-component-name} # Your component name
  |     └── index.tsx           # Main entry point
  ├──  package.json              # Project dependencies and scripts
  ├──  .gitignore                # Git ignore
  └──  README.md                 # README
```

## Getting Started

Start development server:

```bash
blocklet component dev

# or

pnpm run dev
```

Update workspace and project dependencies:

```bash
blocklet component update
```
